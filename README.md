# Tessera for Mac, tester builds

Free tester builds of Tessera. Needs macOS 26 and Google Chrome.

Download the newest build: [Tessera.dmg](https://github.com/Alexandre-Nevero/tessera-releases/releases/latest/download/Tessera.dmg)

## Install

1. Open `Tessera.dmg` and drag Tessera to Applications.
2. Open Tessera from Applications. macOS says it can't check the app: click Done.
3. Open System Settings › Privacy & Security, scroll down, click **Open Anyway**, and confirm. You do this once per version.
4. Tessera opens "Connect Chrome". Follow its three steps. Leave Chrome's Developer mode on.

Apple has not notarized these builds yet. That is why macOS asks.
