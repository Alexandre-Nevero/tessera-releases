# Tessera for Mac, tester builds

Free tester builds of Tessera. Needs macOS 14.4 or later and Google Chrome.

Download the newest build: [Tessera.dmg](https://github.com/Alexandre-Nevero/tessera-releases/releases/latest/download/Tessera.dmg)

## Install

1. Open `Tessera.dmg` and drag Tessera to Applications.
2. Open Tessera from Applications. macOS asks whether to open an app downloaded from the Internet: click **Open**.
3. Tessera opens "Connect Chrome". Follow its three steps. Leave Chrome's Developer mode on.

Apple has notarized these builds, so there is no Open Anyway step.

## Updating

Quit Tessera, download again, and replace the app in Applications.
